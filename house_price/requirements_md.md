# Project Requirements

This project requires the following Python libraries to run successfully. Each library is listed with its version and purpose.

| Library        | Version | Purpose |
|----------------|---------|---------|
| pandas         | 2.1.1   | For data manipulation and handling CSV files. |
| numpy          | 1.26.4  | For numerical computations and array operations. |
| matplotlib     | 3.8.1   | For creating visualizations and plots. |
| seaborn        | 0.12.3  | For statistical data visualization on top of matplotlib. |
| scikit-learn   | 1.3.2   | For machine learning tasks, preprocessing, and model building. |
| joblib         | 1.3.2   | For saving and loading trained machine learning models. |

# Installation

To install all required libraries, run the following command:

```bash
pip install -r requirements.txt
```
