#####	  Abstract	#######

This project predicts whether a passenger on the Titanic survived based on features such as Age,
Fare, Sex, Siblings/Spouses aboard, Parents/Children aboard, Passenger Class, and Port of
Embarkation. The model uses Logistic Regression, a popular machine learning algorithm for binary
classification problems. The project also includes a graphical user interface (GUI) for real-time
prediction.


######	  Introduction   ######

The Titanic disaster dataset is one of the most popular datasets used in machine learning for
classification problems. The goal is to predict survival (1 = Survived, 0 = Not Survived) based on
passenger attributes.


#####     Libraries Used   #####

- pandas: Data loading and cleaning
- numpy: Numerical operations
- scikit-learn: Train-test split, StandardScaler, LogisticRegression
- joblib: Model saving and loading
- tkinter: GUI creation and event handling


#####	System Requirements	#####

>>>>>	Software:

- Python 3.x
- Required Libraries: pandas, numpy, scikit-learn, joblib, tkinter
Hardware:
- Minimum: 2GB RAM, Dual-core processor


#####	 Data Preprocessing	#####

- Dropping unnecessary columns: 'Passengerid', 'zero'
- Handling missing values: Filling with column mean
- Splitting data into features (X) and target (Y)


#####	 Machine Learning Model	#####

- Algorithm: Logistic Regression (binary classification)
- Train/Test Split: 50% training, 50% testing
- Feature Scaling: StandardScaler used for normalization
- Accuracy: Printed after training (approx. 77-78%)


#####	 Workflow	#####

Dataset → Preprocessing → Feature Scaling → Logistic Regression Training → Accuracy
Calculation → Model Saving → GUI Prediction


#####	GUI Description	#####

- Inputs:
- Age
- Fare
- Sex (1 = Male, 0 = Female)
- sibsp (No. of siblings/spouses aboard)
- Parch (No. of parents/children aboard)
- Pclass (Passenger Class)
- Embarked (Port code)
- Output:
- Displays a message box with prediction (Survived / Not Survived)
